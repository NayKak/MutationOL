Politique de confidentialité — Mutation Online

Dernière mise à jour : 27 septembre 2026

Mutation Online est un jeu de mots en ligne permettant à deux joueurs de s'affronter dans une partie multijoueur.

Données utilisées

Lorsque vous utilisez Mutation Online, l'application peut utiliser :

  • votre pseudo choisi dans le jeu ;
  • un identifiant Firebase permettant d'identifier votre session ;
  • les informations de votre compte Facebook, si vous choisissez de vous connecter avec Facebook, notamment votre nom et votre identifiant de compte ;
  • les données nécessaires au fonctionnement d'une partie en ligne, telles que le code de partie, l'état de la partie et les actions effectuées pendant celle-ci.

Utilisation des données

Ces informations sont utilisées pour :

  • permettre la connexion au jeu ;
  • identifier les joueurs dans une partie ;
  • permettre le fonctionnement des parties multijoueurs ;
  • maintenir et sécuriser les sessions de jeu.

Mutation Online n'utilise pas les informations Facebook pour publier du contenu sur votre compte Facebook.

Services utilisés

Mutation Online utilise Firebase Authentication et Firebase Realtime Database pour l'authentification et le fonctionnement du jeu en ligne.

Une connexion Facebook peut être utilisée uniquement si le joueur choisit volontairement cette méthode de connexion.
